# Nuovo sito SLRE

Progetto Next.js (App Router) + TypeScript.

## Sviluppo

```bash
npm install
npm run dev
```

Apri http://localhost:3000.

## Script

- `npm run dev` — server di sviluppo
- `npm run build` — build di produzione (include il type-check)
- `npm run start` — avvia la build di produzione
- `npm run lint` — ESLint
